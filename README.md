# 💘 love_maker

A Django-based matchmaking app that mixes a compatibility quiz with a lighthearted, joke-driven twist — half genuine, half for laughs.

## Features

- 🔍 Compatibility quiz/calculator
- 💌 Matchmaking logic
- 🎉 Playful, humor-driven user experience

## Tech Stack

- **Backend:** Python, Django
- **Database:** SQLite (default) / PostgreSQL (optional)
- **Frontend:** HTML, CSS, (Bootstrap/Tailwind if used)

## Getting Started

### Prerequisites
- Python 3.x
- pip

### Installation

```bash
git clone https://github.com/sanjana123-b/love_maker.git
cd love_maker
python -m venv venv
venv\Scripts\activate      # Windows
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Then open `http://127.0.0.1:8000/` in your browser.

## Usage

1. Sign up / log in
2. Take the compatibility quiz
3. Get matched based on your results
4. Enjoy the playful match reveal 💘
